How an assessment works

  1. Share your project

    Upload the deck or document that describes the system (.pdf or .pptx), or describe it in your own words. The file is read and deleted immediately.

  2. Answer the assistant

    The assistant asks what the document does not say: who decides, which data, which model, which safeguards. Up to {{ settings.max_interview_rounds }} short rounds.

  3. Act on the report

    Risk category, applicable articles, exact deadlines, GDPR findings and a prioritised plan, every point traced to the legal text. Export it as PDF or JSON.
